Privacidade e LGPD

Em conformidade com a Lei Geral de Proteção de Dados (LGPD - Lei nº 13.709/2018), os registros armazenados podem ser anonimizados ou totalmente excluídos mediante solicitação explícita do titular dos dados.

Aviso de Consentimento: Ao cadastrar um cliente nesta plataforma, garante-se que os dados coletados são estritamente necessários para a prestação e execução do serviço contratado.

Instruções para Publicação (Deploy na Nuvem)

Para disponibilizar este sistema para acesso público via navegador no celular ou computador sem instalação de apps, siga os passos abaixo:

  1. Hospedagem Gratuita da Interface (Frontend): Envie este arquivo `index.html` para serviços como Vercel, Netlify, GitHub Pages ou Firebase Hosting. O acesso estará disponível instantaneamente em um link HTTPS.
  2. Banco de Dados em Nuvem Persistente: O sistema já possui integração configurada via Firebase Firestore SDK. As informações salvas em um celular serão automaticamente sincronizadas com qualquer outro dispositivo que abrir a aplicação.
  3. Acesso em Dispositivos Móveis: Abra a URL gerada no navegador Chrome/Safari do smartphone Android ou iOS. Você também pode clicar no menu do navegador e selecionar "Adicionar à Tela Inicial" para usá-lo como um Web App (PWA).
